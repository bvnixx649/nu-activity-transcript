# การตัดสินใจของงานรายวิชา 273387 (Flutter)

ไฟล์นี้ใช้กับงานส่งวิชาเท่านั้น การตัดสินใจของเดโมและตัวที่จะพัฒนาใช้จริงอยู่ใน [../DECISIONS.md](../DECISIONS.md) ห้ามเอามาปนกัน ถ้าเรื่องไหนเปลี่ยนในไฟล์นี้ ไม่ต้องไปแก้ของเดโม และกลับกันก็เหมือนกัน

## แยกงานเป็น 2 สาย (13 ต.ค. 2569)

| สาย | คืออะไร | เป้าหมาย |
| --- | --- | --- |
| งานรายวิชา | แอพ Flutter ในโฟลเดอร์ `docs/course/` (ตัวโค้ดยังไม่ได้เริ่ม) | ส่งให้ทันกำหนด ใช้วิธีที่อาจารย์สอน ใกล้วันส่งตัดฟีเจอร์ให้ง่ายลงได้ |
| เดโมและตัวใช้จริง | PWA ใน repo นี้ (`src/`) และเอกสารใน `docs/` | กองกิจการนิสิตต้องการให้พัฒนาต่อเพื่อใช้จริงใน มน. หลังส่งวิชาเสร็จจะกลับมาพัฒนาต่อจากเดโมและแนวคิดเดิม |

เหตุผล: ผู้ใช้บอกว่างานวิชาต้อง simplify ให้ส่งได้ ส่วนของจริงต้องคงแนวคิดเดิมไว้ ถ้าตัดฟีเจอร์ในวิชาแล้วไปแก้เอกสารเดโมด้วย แผนของตัวใช้จริงจะหาย

ผลที่ตามมา:
- ตัดหรือเปลี่ยนอะไรในงานวิชา บันทึกที่ไฟล์นี้ ไม่แตะ `docs/DECISIONS.md`, `docs/FEATURES.md`, `docs/ARCHITECTURE.md`
- งานวิชาเอาโค้ดหรือแนวคิดจากเดโมไปใช้ได้ แต่ไม่ต้องตามเดโมทุกอย่าง
- [FLUTTER_PLAN.md](FLUTTER_PLAN.md) คือแผนตั้งต้นที่ยังเท่ากับเดโม จะถูกตัดให้เล็กลงเมื่อใกล้วันส่ง

## ข้อเสนอเรื่องขอบเขต (ยังไม่ได้ตัดสินใจ)

เวลาเหลือ 8 วัน ฟอร์มบอกว่า R1 ถึง R5 ฉบับในฟอร์ม 3 คือฉบับที่ใช้ประเมิน จึงเสนอให้ทำเฉพาะที่ R1 ถึง R5 ต้องใช้ แล้วตัดส่วนอื่นออกตั้งแต่ตอนนี้:
- ทำ: ลงทะเบียนและยกเลิก (R1), QR + GPS (R2), Transcript (R3), รายชื่อ เพิ่มชื่อเอง และ export Excel (R4), ประกาศ + กล่องแจ้งเตือนในแอพ (R5)
- ตัด: Firestore (ใช้ SQLite อย่างเดียว), ห้องแชท, LINE OpenChat, push notification, อัปโหลดรูปโปสเตอร์ (ใช้รูปใน assets), dark mode
- ถ้าตัดฟีเจอร์ไหนที่อยู่ใน R1 ถึง R5 ต้องแก้ R ในฟอร์ม 3 ให้ตรงก่อนส่ง
